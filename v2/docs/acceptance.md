# 検証の範囲

通常のテストでは模擬Agentと固定データを使います。検証コマンドは[開発手順](DEVELOPMENT.md)を参照してください。

| 対象 | 確認する内容 |
|---|---|
| 入力 | ファイル種別、サイズ、パス、静的索引と所有関係 |
| Agent | 読取根拠、出力形式、時間・トークン予算、停止と再試行 |
| 保存 | スナップショットの不変性、所有権、期限、削除 |
| 音 | 同じ入力からの譜面再現、根拠との対応、有限値とクリッピング |
| Web | コードと音の相互参照、認証、質問、差分承認、キーボード操作 |

模擬テストの成功は、実モデルの判断精度を示すものではありません。保存済みの実解析は、その時点で選択した範囲の記録です。

音の聴きやすさ、読解時間への効果、通常のレビューとの比較は、人による評価を必要とします。コード全体や実行時の正しさを音から保証することはできません。

# 呼出・返却・利用をまとめて読む

Agent欄の「呼出・返却・利用の根拠」を開き、呼出箇所を選びます。同じ保存済みスナップショットから、呼び出す箇所、相手の静的な定義、すべての返却候補、結果の利用箇所をまとめて表示します。行番号から読取専用コードへ戻れます。新しいモデル呼び出しは行いません。

| 対象 | 確認できる範囲 |
|---|---|
| TypeScript / TSX | 単純な識別子で参照する関数定義、直接代入されたconst変数の静的参照、呼出結果を含む式 |
| Python | 一意に特定できる単純な関数名・import別名、再代入のないローカル変数参照、呼出結果を含む式 |
| 未解決として残すもの | メソッド・動的な呼出先、値の伝播、変数の再代入・分割代入、入れ子関数への結果の伝播 |

呼出は各関数の先頭24箇所、返却候補・利用は各16箇所までです。上限で省略した場合は表示します。候補がない状態や抽出失敗は、問題なしという判定ではありません。

returnは静的な候補です。実行された経路、返却値、呼出回数、並列実行を推測しません。複数のreturnがあれば全候補を表示し、選ばれた経路の印を付けません。変数の参照も、実行時にその値が使われた証明ではありません。

「この関係の旋律を試聴」は、根拠範囲と重なる保存済みの意味イベントだけを、譜面上の順で最大10秒聴きます。Code Grooveの責務の旋律を維持し、対象外の小節を省略します。静的な関係の表示順を実行順として演奏するものではありません。意味が未調査の範囲には音を追加せず、音に収まらない根拠もコードで読めます。終了・取消・失敗後は元の再生設定と位置へ戻り、一時停止します。

着想の参考は[SoundCoding2026の固定版](https://github.com/kouduki1101/SoundCoding2026/tree/3261ef988c57c5be1c42e5d0ee42182542759c84)です。呼出・返却・利用の根拠をまとめて表示する発想を参考にしています。参考先のコード・音源の流用はありません。

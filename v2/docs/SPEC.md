# 動作仕様

Code Grooveは、コードの静的な調査結果と根拠を音・タイムライン・ソース表示で確認するためのツールです。通信契約は`apps/backend/code_groove/schemas.py`を正本とし、JSON SchemaとTypeScript型を生成します。

## 入力と解析

TypeScript、TSX、Pythonを対象とします。公開リポジトリの固定commit、または認証済み利用者が提供するcommit済みスナップショットを取り込みます。パス、リンク、ファイル種別、サイズを検証します。

解析対象のコードは実行しません。信頼済みの静的パーサーで索引を作り、Agentには読取と制限付きの提出ツールを提供します。ソースやコメントをシステムへの命令として扱いません。

調査した実装には、そのスナップショットの読取記録と根拠範囲を結び付けます。読んでいない実装や確認できなかった情報は、未調査・不明として残します。選択範囲の解析結果を、リポジトリ全体の検証結果として扱いません。

## 結果と音

模擬データ、保存済みの実解析、新規の実解析を画面で区別します。実解析が失敗したときに、模擬結果へ自動で切り替えません。

Agentの責務・意味イベント・根拠を検証してから、固定規則で譜面へ変換します。同じ解析結果・規則・音源からは同じ譜面を生成します。音の違いだけで欠陥、深刻度、品質を判定しません。

音やタイムラインから根拠コードへ移動でき、音を使わずに説明と根拠を読む操作も提供します。保存済みの説明や譜面の閲覧では、新しいモデル呼び出しを行いません。

## 調査と承認

新規解析・追加調査は認証した利用者の明示操作で開始します。時間、モデル要求数、ツール数、トークン、日次利用枠を制限し、取消と失敗を表示します。

改善案は差分として提示し、人が承認した場合だけアプリ内の新しいスナップショットへ反映します。元のソースと解析結果は保持します。元リポジトリへの変更やpushは行いません。

## 保存と運用

私有プロジェクトは所有者だけが閲覧できます。アクセス期限、削除要求、ジョブのleaseと再試行を検証します。ソースと成果物の保存先、workerを非公開にします。

モデルの解釈精度、実行時の動作、音による読解の効果は別の検証事項です。技術テストの成功を、それらの保証として扱いません。
